# 🍡 말랑 친구들 퍼즐

이웃한 친구 둘을 바꿔서, 같은 친구 3마리 이상을 한 줄로 모으는 퍼즐 게임이에요.

## 실행 방법
`index.html` 파일을 더블클릭하면 브라우저에서 바로 실행돼요. (설치할 것 없음!)

## 바꿔보기 좋은 곳
`index.html` 안의 **설정** 부분만 고쳐도 게임이 달라져요.
- `SIZE` : 판 크기
- `MOVES` : 이동 가능 횟수
- `GOAL` : 목표 점수
- `CHARACTERS` : 캐릭터 색깔과 귀 모양. 직접 그린 그림을 쓰려면 `image: "images/파일이름.png"` 를 추가하세요.

# I-Cube E 패키지 빌드업 애니메이션

`icube-e/index.html` 은 삼성 I-Cube E(RDL 인터포저 + 임베디드 실리콘 브리지, 16단계), TSMC CoWoS-L(RDL 인터포저 + LSI 브리지, 17단계), 인텔 EMIB-T(기판 내장 TSV 브리지, 10단계)의 빌드업 과정을 단면 애니메이션으로 보여 주는 교육 자료입니다. 브라우저로 열면 바로 실행됩니다.

- 탭: `I-Cube E` / `CoWoS-L` / `EMIB-T` / `나란히 비교` (같은 목적의 공정 단계끼리 16개 행으로 맞춰 동시 재생). 주소 끝에 `#icube-e`, `#cowos-l`, `#emib-t`, `#compare` 를 붙이면 해당 화면으로 바로 열립니다.

- 공개된 구조 정보(전자신문 2023.11, Samsung Foundry Forum 보도)를 바탕으로, 상세 공정은 업계 일반의 칩 라스트 임베디드 브리지 공정으로 재구성한 예시입니다. 실제 양산 공정과 다를 수 있습니다.
- 조작: ◀/▶ 버튼 또는 방향키, 스페이스바로 재생/정지, 슬라이더나 단계 목록 클릭으로 이동
